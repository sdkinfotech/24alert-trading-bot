## Задача
Исследование ai.finam.ru — можно ли программно доставать аналитические данные (рейтинги, AI-прогнозы, настроение трейдеров и т.д.).

## Что сделано

### 1. Разведка ai.finam.ru (AI-скринер)

**ai.finam.ru** — это «Финам AI-скринер», веб-инструмент аналитики на базе ИИ.

**Возможности скринера:**
- Анализ 70+ финансовых метрик (мультипликаторы, ТА, макро)
- AI-рейтинг инвестиционной привлекательности
- AI-факторы и моментум-индикаторы
- Настроение трейдеров (быки/медведи, уровень уверенности)
- Техническая аналитика (EMA, MACD, RSI, стохастик, свечные паттерны)
- Бэктестинг стратегий («машина времени» — почти год истории)
- Автоматическая AI-интерпретация финансовых отчётов
- Покрытие: акции РФ, акции США, облигации РФ, фьючерсы, валюты, индексы, крипто, азиатские рынки

**Публичный API: НЕТ.**
Скринер — закрытый веб-продукт без документированных API-эндпоинтов. Сайт защищён антибот-системой (блокирует запросы из серверных сред, VPN, прокси). Парсинг нецелесообразен и ненадёжен.

### 2. Finam Trade API (api.finam.ru) — отдельный продукт

**Trade API** — это публичный API для алготрейдинга, НО он не предоставляет данных AI-скринера.

| Характеристика | Значение |
|---|---|
| Протоколы | gRPC (`api.finam.ru:443`), REST (`api.finam.ru`), WebSocket (`api.finam.ru/ws`) |
| Аутентификация | secret token → JWT (15 мин) |
| Rate limit | 200 req/min на метод |
| Обработка ордера | 68.7 мс |
| Uptime | 99% |
| Техобслуживание | 05:00–06:15 MSK ежедневно |
| Демо-счёт | Бесплатно (без реального брокерского) |

**Что даёт Trade API:**
- Рыночные данные: свечи (M1–Monthly), котировки, стакан, последние сделки
- Управление заявками: market, limit, stop, take-profit, stop-loss
- Портфель: позиции, баланс, маржа, история сделок и транзакций
- Инструменты: 3500+ акций РФ, 8000+ US equities, облигации, ETF, фьючерсы, опционы
- Новости: RSS-фиды (finam.ru/analysis/conews/rsspoint/ и international/advanced/rsspoint/)

**Чего НЕ даёт Trade API (есть только в скринере):**
- AI-рейтинги инвестиционной привлекательности
- AI-прогнозы
- AI-факторы и моментум
- Настроение трейдеров
- Автоматический анализ финотчётности

**Go SDK (community):**
- gRPC: `github.com/Ruvad39/go-finam-grpc`
- REST: `github.com/Ruvad39/go-finam-rest`

### 3. Finam MCP Server — обёртка Trade API для AI-ассистентов

- PyPI: `finam-mcp-server` v0.2.0 (Python 3.12+)
- GitHub: `github.com/FinamWeb/finam-mcp` (официальный, MIT)
- Также JS-версия: `github.com/mishgancheg/mcp-finam-trade-api`
- Установка: `uvx finam-mcp-server@latest`
- Scope: тот же что Trade API (рыночные данные + торговля). Скринерных данных нет.

### 4. Termo.ai Finam Skill

- Обёртка Trade API через Termo/ClawHub
- Включает скрипт volatility scanner (топ-100 по волатильности)
- Списки top_ru_equities.json / top_us_equities.json
- Тот же scope — торговые данные, не аналитика скринера.

## Выводы

### Что можно получить программно (через Trade API):

| Данные | Протокол | Полезность для 24alert |
|---|---|---|
| Котировки real-time | REST/gRPC/WS | Высокая — для алертов по цене |
| Исторические свечи | REST/gRPC | Высокая — для расчёта своих индикаторов (MA, RSI, MACD) |
| Стакан заявок | REST/gRPC | Средняя — для анализа ликвидности |
| Новости (RSS) | HTTP GET | Средняя — для новостных алертов |
| Портфель/позиции | REST/gRPC | Высокая — для мониторинга |
| Управление заявками | REST/gRPC | Высокая — для автоторговли |

### Что НЕЛЬЗЯ получить программно (закрыто в скринере):

| Данные | Альтернатива |
|---|---|
| AI-рейтинги | Считать свои на основе мультипликаторов из открытых источников |
| AI-прогнозы | Строить свои ML-модели на исторических свечах |
| Настроение трейдеров | Парсить другие источники (sMart-lab, TradingView, social sentiment) |
| AI-факторы/моментум | Считать самостоятельно (RSI, MACD, momentum — это стандартные ТА-индикаторы) |

### Рекомендация

1. **Интегрировать Finam Trade API** как источник рыночных данных для 24alert — это покрывает основные потребности (котировки, свечи, стакан, торговля).
2. **Не пытаться парсить ai.finam.ru** — антибот-защита, нет API, ненадёжно, юридически сомнительно.
3. **Для AI-аналитики** — строить собственные модели на данных Trade API. Индикаторы (MA, RSI, MACD, momentum) считаются тривиально из свечей.
4. **MCP-сервер Finam** можно подключить в Cursor для оперативного анализа рынка прямо из IDE (уже поддерживается, MIT лицензия).
5. **Go SDK** — использовать `go-finam-grpc` для интеграции в бэкенд 24alert (язык проекта — Go).
