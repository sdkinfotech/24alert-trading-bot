### 📊 Масштабирование (на будущее)

**Текущие ограничения:**
- RAM: 3.8 GB — достаточно для 2-3 микросервисов в разработке; при production требуется минимум 8-16 GB

- CPU: 2 cores — достаточно для разработки; для production требуется минимум 4-8 cores

**Рекомендации:**
- Настроить мониторинг disk usage (alert на 80% заполнения)
- Настроить log rotation для предотвращения переполнения `/var`
- При переходе на production: запросить upgrade до 8GB+ RAM, 100GB+ SSD диска, 4+ cores
