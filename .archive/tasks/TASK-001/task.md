# TASK-001: Первое подключение к серверу и проверка ресурсов

## Описание
Установить базовое подключение к production-серверу алготрейдинговой платформы и проверить доступные ресурсы (CPU, память, диск, сетевые интерфейсы). Убедиться, что окружение готово к развёртыванию сервисов.

## Требования
- Подключение по SSH к серверу (адрес и учётные данные в секретах)
- Проверка конфигурации системы (OS, ядра, ОЗУ)
- Проверка доступного дискового пространства
- Проверка сетевых интерфейсов и доступности внешних сервисов
- Валидация прав доступа для деплоя
- Подготовка логов для диагностики

## Критерии готовности (DoD)
- [x] Подключение установлено и проверено
- [x] Ресурсы задокументированы в handoff
- [x] Все необходимые утилиты присутствуют (git, docker, kubectl если нужны)
- [x] Права доступа настроены
- [x] Дефекты и ограничения выявлены и зафиксированы

## Зависимости
Нет. Это задача инициализации.
