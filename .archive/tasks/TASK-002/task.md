# TASK-002: Базовый торговый робот (Go, микросервисы)

## Описание
Спроектировать и реализовать базового торгового робота на Go с микросервисной архитектурой. Робот не содержит встроенной стратегии — стратегия подключается как плагин через интерфейс. Робот должен уметь работать со всеми типами заявок, отслеживать позиции, управлять рисками и предоставлять CLI + Swagger API.

## Требования

### Функциональные
- Все типы заявок: market, limit, stop, stop-limit, iceberg; создание, отмена, модификация, отслеживание статуса
- Управление позициями: открытие, закрытие, частичное закрытие, PnL (realized/unrealized)
- Market data: котировки, стакан (orderbook), свечи (candles), тики
- Портфельная информация: балансы, активы, история операций
- Риск-менеджер: лимиты по позиции, exposure, drawdown, макс. убыток за сессию
- Подключаемая стратегия: интерфейс Strategy с методами OnTick, OnOrderUpdate, OnStart, OnStop
- Структурированное логирование всех действий (заявки, исполнения, ошибки)
- CLI для управления роботом и просмотра состояния
- Swagger/OpenAPI для всех REST-эндпоинтов

### Нефункциональные
- Язык: Go (компилируемый, высокая производительность)
- Архитектура: микросервисы, gRPC между сервисами, REST наружу
- Event-driven: NATS или Redis Streams для событий (fills, ticks, risk alerts)
- Структурированные логи (zerolog/zap), correlation ID
- Docker-контейнеры для каждого сервиса
- Mono-repo с Go workspace

## Критерии готовности (DoD)
- [ ] Проект инициализирован (Go workspace, модули, proto)
- [ ] Все 6 микросервисов компилируются и запускаются
- [ ] Order service: CRUD заявок всех типов через gRPC и REST
- [ ] Marketdata service: подписка на котировки (mock/simulator)
- [ ] Portfolio service: балансы и позиции
- [ ] Risk service: проверка лимитов перед отправкой заявки
- [ ] Strategy interface определён, mock-стратегия работает
- [ ] CLI управляет роботом (start/stop, статус, заявки)
- [ ] Swagger документация для всех REST endpoints
- [ ] Docker Compose поднимает всю систему
- [ ] Интеграционные тесты: order flow от заявки до исполнения
