# Backend — TASK-007: Закрытие портов

## Контекст

Задача: закрыть прямой доступ к портам микросервисов (9001–9004, 9090) из интернета.
Текущее состояние: порты биндятся на `0.0.0.0`, доступны извне.

## Что сделать

1. Открыть `/opt/24alert/deployments/docker-compose.yaml` на сервере (или локально в `c:\Users\sdk\24alert-trading-bot\deployments\docker-compose.yaml`)
2. Изменить секцию `ports` для каждого микросервиса:
   - Было: `"9001:9001"` → Стало: `"127.0.0.1:9001:9001"`
   - Аналогично для 9002, 9003, 9004
3. Для Prometheus: `"9090:9090"` → `"127.0.0.1:9090:9090"`
4. Gateway (`:18080:8080`) — оставить как есть, он уже забинден на 127.0.0.1
5. Сохранить diff в `artifacts/docker-compose.patch`
6. Применить изменения и проверить
