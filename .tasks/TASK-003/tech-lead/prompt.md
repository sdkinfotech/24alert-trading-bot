Ты — **Техлид**. Задача — провести final review процесса развёртывания и smoke testing. Убедиться, что система production-ready и готова к использованию.

## Что проверять

### 1. Deployment процесс
- [ ] Документирован (DEPLOYMENT.md)
- [ ] Воспроизводим (можно развернуть заново)
- [ ] Безопасен (т.о. нет в git, env vars корректны)
- [ ] Быстр (<10 минут от git clone до docker-compose up)

### 2. Runtime state
- [ ] Все 5 контейнеров в статусе Up
- [ ] Health checks проходят
- [ ] Логи структурированы и читаемы
- [ ] Нет ошибок в логах при нормальной работе

### 3. API функциональность
- [ ] Все smoke tests пройдены
- [ ] Ответы соответствуют контрактам (swagger)
- [ ] Время ответа приемлемо (<1s)
- [ ] Rate limiting работает

### 4. Безопасность
- [ ] T-Invest токен не в логах
- [ ] .env не коммитится
- [ ] No hardcoded secrets в коде
- [ ] SSH доступ требует ключ

### 5. Готовность к MVP
- [ ] Можно принимать реальные заявки через CLI/API
- [ ] Портфель отслеживается в реальном времени
- [ ] Risk validation работает
- [ ] Документация достаточна для пользователя

---

## Красные флаги (блокеры)
- Токен leakage в логах
- Контейнеры падают при нормальной работе
- Rate limit не соблюдается
- Swagger не совпадает с реальными endpoints
