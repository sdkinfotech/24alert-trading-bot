# План: TASK-001

## Тип задачи
Инициализация инфраструктуры — первое подключение и валидация ресурсов production-сервера.

## Порядок ролей в конвейере
```
Планировщик (ВЫ) → DevOps ✅ → Техлид ✅ DONE
```

## Последовательность и зависимости

| Роль | Задача | Входные данные | Выходные артефакты | Зависит от |
|------|--------|----------------|--------------------|-----------|
| **DevOps** | Подключиться к prod-серверу, собрать метрики ресурсов, проверить окружение | Адрес и секреты сервера (должны быть в `.env` / vault) | Документированные ресурсы, валидация окружения, рекомендации | Секреты в place |
| **Техлид** | Провести code review результатов, убедиться в completeness и безопасности | handoff от DevOps | Approval или замечания | DevOps handoff |

## Критерии готовности (DoD из TASK-001)
- ✓ Подключение установлено и проверено
- ✓ Ресурсы задокументированы в handoff
- ✓ Все необходимые утилиты присутствуют (git, docker, kubectl)
- ✓ Права доступа настроены
- ✓ Дефекты и ограничения зафиксированы

## Риски и примечания
1. **Секреты**: DevOps должен использовать существующий механизм хранения (`.env`, vault, AWS Secrets Manager).
2. **Безопасность SSH**: логи подключения и команды не должны содержать sensitive data.
3. **Документация**: результаты должны быть воспроизводимы для следующих развёртываний.
4. **Rollback**: если обнаружены критические проблемы — техлид отправляет на пересмотр.
