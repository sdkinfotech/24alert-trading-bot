# TASK-007: План работы — Закрытие портов микросервисов

## Goal

Закрыть прямой доступ к портам микросервисов (9001–9004, 9101–9104, 9090) из интернета. Сделать их доступными только через loopback (127.0.0.1).

**Итого**: ~2.5 дня

## Детали по этапам

### Backend (изменение docker-compose.yaml)

Текущие порты в `docker-compose.yaml`:
```yaml
ports:
  - "9001:9001"    # order-svc — доступен на 0.0.0.0
  - "9002:9002"    # marketdata-svc
  - "9003:9003"    # portfolio-svc
  - "9004:9004"    # risk-svc
```

Нужно изменить на:
```yaml
ports:
  - "127.0.0.1:9001:9001"    # order-svc — только localhost
  - "127.0.0.1:9002:9002"
  - "127.0.0.1:9003:9003"
  - "127.0.0.1:9004:9004"
  - "127.0.0.1:9090:9090"    # Prometheus
  - "127.0.0.1:9101-9104"    # метрики сервисов (если нужно)
```

Gateway остаётся:
```yaml
- "127.0.0.1:18080:8080"   # nginx проксирует наружу
```

### DevOps (деплой)

1. Пересобрать compose на сервере
2. Роллинг-рестарт контейнеров
3. Проверить доступность портов извне (должны быть закрыты)
4. Проверить внутреннюю связь (gateway → микросервисы через 127.0.0.1)
5. Настроить SSH-туннель для Prometheus или VPN-доступ

### Tester

1. `nmap -p 9001-9004,9090 176.123.160.234` — все порты должны быть filtered/closed
2. `curl https://gateway.24alert.ru:8080/health` — должен работать
3. Через SSH-туннель: `curl http://127.0.0.1:9090/metrics` — Prometheus доступен
4. API-клиенты Traderbook должны продолжать работу
